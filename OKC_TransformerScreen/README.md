# OKC Transformer Screen

A cylindrical perforated metal screen wall with stencil **O / K / C** cut-outs,
standing on a concrete curb. Modelled after the transformer enclosure in the
plaza at NW 4th and Robinson in downtown Oklahoma City. Built as a static prop
for a PowerWash Simulator 2 mod.

Everything is generated by one Blender script, so any dimension, the letter
mix, the panel count or the hole density can be changed by editing the
parameters at the top of `build_okc_screen.py` and re-running it.

## Files

| Path | What it is |
| --- | --- |
| `build_okc_screen.py` | Generator. Builds the mesh, exports, saves the .blend, renders previews. |
| `verify_okc_screen.py` | Checks the dirt-mask UVs and mesh hygiene. Prints `VERIFY: PASS` or `FAIL`. |
| `build_okc_dirtmaps.py` | Paints the layered control maps `export/dirt/CM_<object>.png` (see "Dirt layers"). Prints `DIRTMAPS: PASS` or `FAIL`. |
| `OKC_TransformerScreen.blend` | Saved scene (Blender 5.1). Includes a preview camera and sun. |
| `export/OKC_TransformerScreen.fbx` | Unity-ready FBX, Y up, metres, both UV maps, tangents. |
| `export/OKC_TransformerScreen.glb` | Same asset as binary glTF for runtime loaders. |
| `preview/*.png` | Renders plus a dirt-atlas coverage image from the verifier. |

## What is in the mesh

| Object | Tris | Verts | Material | Notes |
| --- | --- | --- | --- | --- |
| `OKC_Screen_Panels` | 74,548 | 36,004 | `OKC_Screen_Metal` | 14 panels, each a closed watertight shell with 8 mm thickness. |
| `OKC_Screen_Plinth` | 864 | 576 | `OKC_Concrete` | Concrete curb ring. Bottom face left open, it sits on the ground. |

Both are parented to an empty named `OKC_TransformerScreen` whose origin is
the centre of the ring at ground level.

Dimensions: 9.00 m outer diameter, wall 2.30 m tall on a 0.15 m curb, so the
top edge is at 2.45 m. Real-world scale, 1 Blender unit = 1 m.

Letter layout is seeded random (seed `20260527`). Each panel has 4 loose
rows. A row is packed left to right with letters drawn at random from big
O, big C, K, small o and small c, separated by jittered gaps, with the
leftover width spread evenly so spacing stays consistent. Every letter then
gets an arbitrary rotation and a vertical wobble, kept at least 4 cm clear of
its neighbours. That gives the scattered-but-evenly-spaced look of the real
screen: 284 glyphs in total, no column alignment. Change `SEED` for a
different arrangement, or `LETTER_WEIGHTS`, `GAP_TARGET`, `ROW_V_JITTER` and
`SMALL_SCALE` to tune the look.

## UV maps

The dirt system in PowerWash Simulator paints into an opacity mask through a
second UV set that has to follow lightmap rules: no overlapping shells,
everything inside 0 to 1, and a margin between shells. The mesh ships with:

- **`UVMap`** (Unity `uv` / `TEXCOORD0`): base texture UVs. One UV unit is
  one metre, so a tiling metal or concrete texture drops straight on.
- **`DirtMask`** (Unity `uv2` / `TEXCOORD1`): dirt-mask atlas. Each panel's
  outer face and inner face is its own island. Hole walls are packed into thin
  strips in the spare atlas space.

Verified at 2048 x 2048: zero overlapping texels, 63.7% atlas utilisation on
the panels and 58.7% on the curb.

| Surface | Dirt-mask density | At a 2048 mask |
| --- | --- | --- |
| Panel faces, inside and out | 0.0782 UV per metre | about 6.2 mm per texel |
| Hole walls (8 mm rims) | 0.0565 UV per metre | about 8.6 mm per texel |
| Curb | 0.2043 UV per metre | about 2.4 mm per texel |

## Dirt layers

`build_okc_dirtmaps.py` paints one 1024² control map per wash target (R, G, B = opacity of palette layers 0, 1, 2)
the way the game's own levels layer dirt: a tough bottom layer under easy coats, nested masks, soft edges. The
palettes that give each channel its dirt type are built in `PWS2LevelKit/.../OkcPack.cs` (`ImportRing`) and must
list the layers in the same order.

| Target | R (layer 0) | G (layer 1) | B (layer 2) |
| --- | --- | --- | --- |
| Panels (`TPL_OKC`) | rust flakes, Tier 6: `RUST_COVERAGE` (35%) of each panel, patches weighted to the bottom and the seams | grime, Tier 1: every texel, varying opacity | mud splats, Tier 1: blobs, more low down |
| Curb (`TPL_OKC_Curb`) | slimy grime, Tier 1: every texel | sand, Tier 1: patches, more low down | cracked mud, Tier 3: patches inside the sand |

The grime covers the rust, so washing reveals the flakes, and those need a nozzle that can clean Tier 6. Every
non-zero value is at least 64, so the game's start-dirtiness count equals the kit's count of texels with any dirt.
Faces looking into the closed ring stay clean.

```bash
"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" -b OKC_TransformerScreen.blend --python build_okc_dirtmaps.py
```

## Unity import notes

1. Drop `export/OKC_TransformerScreen.fbx` into the project. Leave **Scale
   Factor** at 1 and **Convert Units** on. It arrives at 9 m across.
2. **Normals: Import**, **Tangents: Import** or Calculate. Sharp edges are
   already marked in the mesh.
3. Turn **Generate Lightmap UVs off**. The second UV map is already there and
   Unity would overwrite it.
4. Set **Mesh Compression** to Off so the UVs are not quantised.
5. Add a **Mesh Collider** to each mesh. Both are static, so non-convex is
   fine. Holes are real geometry, so spray passes through them.
6. Which UV channel the game's dirt shader reads from is something to confirm
   in-game with UnityExplorer. `DirtMask` lands in `mesh.uv2`.

For a runtime loader that takes glTF, `export/OKC_TransformerScreen.glb`
carries the same two UV sets as `TEXCOORD_0` and `TEXCOORD_1`.

## Known limitations and easy follow-ups

- The letter sequence is random, it does not spell OKC in order like some
  panels on the real screen do.
- No door, hinges or transformer inside. The real ring has a hinged access
  panel; adding a plain panel with hinge pins is a small change to
  `build_panel_2d`.
- No textures. Materials are flat colours so the modder can assign in-game
  materials.
- Hole walls get about 72% of the face texel density because they are packed
  into leftover atlas space. They are 8 mm deep, so this is hard to notice.
- All 14 panels are one mesh with one dirt mask. If the game's per-object
  mask resolution turns out to be low, split the mesh by loose parts in
  Blender; each panel already has its own UV islands.
